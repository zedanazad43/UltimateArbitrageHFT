# UltimateArbitrageHFT

Deployed Cloudflare Worker: \rbitrage-bot\

## Setup
1. Copy \pi_keys.txt\ or \.env\ **with real keys/secrets** to the project root.
2. Run:
    npm install
3. Run tests (all must PASS):
    npm test
4. Deploy:
    npm run deploy
    # or
    wrangler deploy
5. **Secrets are managed via \pi_keys.txt\ or \.env\. These files MUST NOT be in version control!**

Check \.gitignore\ is configured correctly.
