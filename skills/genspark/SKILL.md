# Genspark AI Skill

Use Genspark as a browser-based agent fallback when LLM providers fail.

## Trigger
- User mentions "genspark", "spark", or asks for deep research
- All LLM providers (OpenAI/Anthropic) are unavailable

## Actions
- Open https://www.genspark.ai/ in browser
- Submit prompt
- Extract result
- Return to user
